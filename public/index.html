Run it yourself

Self-host the web app

This is open source and there's no build step — clone it and run it on your own machine or server.

git clone https://github.com/schlangens/ir-logger.git
cd ir-logger
npm install
npm start

Full setup details are in the project's readme on GitHub.

Offline desktop tool

The original version of this project: a standalone desktop app for one analyst logging findings to local Markdown files. No server, no account, no network at all.

Download the desktop tool (ir-logger.py)

Needs Python (with its bundled tkinter module); pasting images from the clipboard needs one extra package, Pillow (pip install pillow). It's a single analyst working alone on one machine — no live sharing, ATT&CK tagging, or audit log like the web app above.
